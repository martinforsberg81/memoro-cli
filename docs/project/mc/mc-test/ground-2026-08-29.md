## One step that comes before A, in the other repository

`memoro/scripts/testing/runner.mjs:108` is
`if (result.code !== 0 || result.signal) break;` — verified still exactly that
on 2026-08-29. The batches are separate `node --test` processes (standard 2,
sqlite 1, heavy 1), so a red standard batch means sqlite and heavy never run,
and `tapTotals` takes the last `# tests` line — so an aborted run reports
`finished: true` over a truncated red set. Two truncated sets match each other
and read as "no new red".

That is a change in the **memoro** repository, so it is its own step and its own
PR against that repo. It is the first of the ruling's three non-negotiable
conditions and it lands before A is put to work.
