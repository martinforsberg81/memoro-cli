section: Changed

- **An area may carry several repair programmes, and a repair programme several live goals; no change needs a horizon.** `mc goal new` no longer refuses a second live goal in an area repair programme, and `mc programs create --area` no longer refuses a second open repair programme for the same area. A change is ordered as a programme document, a repair programme for a set of small adjustments, and the planner cuts its goals from it. The area check still refuses an area the repository does not declare.
