section: Changed

- **Design has two places.** `docs/technical/` describes what runs; the
  programme's README and goals hold what is being built. Canon no longer sends
  sessions to a programme's `docs/project/<programme>/rulings.md`, and jev, the
  goal-less `mc ask` and the Martin queue no longer carry its rulings: the
  programme README is what is sent. The canon roles and tasks state the rule,
  and the plan session sheds a README section once its goal has landed and
  `docs/technical/` holds it. `docs/project/` is history and is not written;
  existing files there are not moved or removed.
