section: Changed

- **The workareas no project explains moved from PROGRAMMES to WORK.** They
  were the tail of the projects section, which made it answer two questions at
  once — where the work stands, and which directories are left over. The second
  is WORK's: a folder with nothing to explain it is work in exactly the sense
  that heading means, and it is often the same folder somebody has a session
  open in. The heading counts both now — `4 sessions · 40 workareas with no
  project` — and the numbering is unchanged, so a number still opens the row it
  is beside.
