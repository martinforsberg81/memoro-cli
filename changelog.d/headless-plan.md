section: Changed

- **A blocked goal wakes a headless plan session.** A goal blocked by a red
  review, a red merge or the runner (three sessions without a word, no verdict,
  no pull request, an `after` gone) is a candidate for a free lane of kind
  `plan`: one session on the plan role's model (fable, ruling 6), in the
  programme's directory and never the goal's worktree. It reopens the goal,
  replaces it, or leaves it blocked with a question for Martin. A goal it left
  blocked gets the runner's entry and wakes nothing again; the page and
  `mc goal list` draw it `waits on a person`.
- **The mend is gone.** `src/mc/mend.js`, `canon/roles/mend.md`, the merger's
  mend line and `mc publish --branch` are removed. A red on a project's pull
  request goes to the step's next session (ruling 30); a red on a goal's blocks
  it, which wakes plan. A `mending` entry an older merger left reads as
  `queued`.
