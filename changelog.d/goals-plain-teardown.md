section: Removed

- **The autonomous goal machinery is gone.** The mc-plan v2 model — goal state
  files, revisions, leases, the capability report, its own review and merge
  door, `mc programme` and `mc session-control` — is removed whole, and the old
  `mc goal` with it. `mc publish`, `mc merge`, the merger and the merge boundary
  have one path again. A version 2 plan is reported as unsupported.
