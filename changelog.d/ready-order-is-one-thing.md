section: Changed

- **The desk sets a programme ready on Martin's word and brings him a ready order as one thing.** Martin says a programme is ready and the desk runs `mc programs state <programme> ready`; the canon no longer tells him to run the verb, which his own shell refuses. Before a document is brought to be set ready, the desk settles its open details itself and writes each reading under Decided, and an act of his that follows from the order is brought afterwards as that act alone, never in a list of open points.
