  folder a plan or remove it by hand. Both are questions a machine must not
  answer — a missing note never stops an archive, and no machine removes a
  workarea with no plan — so this is where they get asked. A file the runner
  has never written is reported as absent rather than as "none": a clean
  board the brief never looked at is the one thing worse than a list.
