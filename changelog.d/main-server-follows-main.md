section: Changed

- **The shared checkout's dev server stays up and follows main, and `mc shot dev --main` shows how the app is now.** The server of `~/mc/self/memoro` used to be admitted, counted and evicted like a worktree's, so a "how is it now" screenshot waited a cold start (~190 s) behind worktree servers. It is now mc's standing server: never stopped as a stale holder, not counted against `MC_DEV_MAX_SERVERS`, started again when gone, and marked `(main)` in `mc dev status`. When idle for `MC_DEV_MAIN_IDLE_SECONDS` (60) it is fast-forwarded to `origin/main` (only when clean and on main) and restarted before serving; a busy one, or one a kept browser stepped on in the last 60 s, is served as it is. `--main` serves that server from inside a worktree; without it the worktree you stand in is served as before.
