section: Changed

- **Each repository's whole suite runs on main whenever main moves, beside all other work (Martin, 2026-11-13).** The once-a-day nightly tick is gone. The runner starts a full run of a repository when its origin/main moved since its last measured full run. There is one run per repository at a time, and a run that ends starts the next only if main moved meanwhile. A run takes no round lock and no lease, measures in its own checkout (`~/mc/gate/<repo>/full`) at 2 test lanes (`MC_FULL_RUN_LANES`), and hands the reds it finds on main to the `main-health` repair goals. The stall watchdog now sees a whole suite's progress through a per-file process heartbeat. node's in-order reporter hid it, and every full run on mc-server had been stopped as stalled with no file named. `tests/mc/logger.test.js` no longer hangs on Linux.
